# Données

Ce dossier contient les données utilisées par l’application : fixtures, imports CSV et exports.

## Sous-dossiers
- imports/: fichiers CSV d’import de données métier
- fixtures/: données de test ou exemples
- exports/: exports de sauvegarde ou de rapport

## À savoir
- Les imports CSV doivent respecter le format défini dans les README des sous-dossiers.
- Les fichiers de fixtures ne doivent pas être modifiés sans vérifier leur impact sur les tests.
- Les exports doivent être conservés avec une date ou un nom explicite.
