# Architecture

Ce dossier rassemble les documents d’architecture du projet.

## Contenu
- mcd.md et mld.md: modèle conceptuel et logique des données
- decisions.md: décisions techniques importantes
- diagrammes/: schémas et représentations visuelles

## À savoir
- Mettre à jour ces documents lorsqu’un changement majeur impacte les modèles ou l’architecture.
- Les schémas doivent rester cohérents avec les modèles Django et la base de données.
