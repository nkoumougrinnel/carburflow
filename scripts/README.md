# Scripts

Ce dossier regroupe les scripts utilitaires pour le déploiement, la maintenance et l’import des données.

## Scripts principaux
- deploy.sh: déploiement et reconstruction des conteneurs
- backup.sh: sauvegarde de la base de données
- restore.sh: restauration de la base
- seed-db.sh: peuplement de données
- start-api.sh / start-frontend.sh: lancement rapide des services

## À savoir
- Exécuter les scripts depuis la racine du projet si possible.
- Vérifier les permissions d’exécution avant utilisation.
- Les scripts doivent être conservés simples et documentés.
